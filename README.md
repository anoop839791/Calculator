# 🧮 Calculator

A modern, responsive calculator built using **HTML, CSS, and JavaScript**.

This project provides a clean and user-friendly interface with basic arithmetic operations, keyboard support, responsive design, and smooth button interactions.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- `%` Percentage
- 🔄 Clear display
- ⌫ Delete / Backspace
- 🔢 Decimal calculations
- ⌨️ Keyboard support
- 📱 Responsive design
- 🎨 Modern dark UI
- ⚡ Real-time display
- 🚫 Division-by-zero error handling

## 🛠️ Technologies Used

- **HTML5** — Structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Calculator logic and interactions
